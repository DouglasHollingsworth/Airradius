# GPT Store build kit — not created or published

Use builder-config.json, instructions.md, training-handbook.md and openapi.json in an eligible GPT Builder. The icon is in ../plugin/assets/logo.png. Actions use three read-only public GET endpoints and no authentication because they accept only built-in fictional presets. A valid published privacy URL is provided.

Account eligibility must be checked before creation. Current OpenAI Help states that personal Free, Go, Plus and Pro accounts cannot create or publish new GPTs; managed workspaces depend on role and workspace permissions. Existing eligible GPTs may be editable. Affected Enterprise custom GPT retirement is planned for December 11, 2026; other account notices may differ. Do not buy an upgrade or create a second provider/account to work around restrictions.

Official source checked 2026-10-06: https://help.openai.com/en/articles/8798878-sharing-and-publishing-gpts

Endpoint tests prove the API works. They do not prove GPT Builder import, natural-language tool selection, model refusal behavior, store eligibility or approval. Those checks remain pending until the owner grants access to an eligible existing GPT or workspace. This folder is also a migration reference; the portable plugin package is the current primary directory path.

Before public sharing: validate Builder import, run the five positive and three negative reviewer prompts in an actual chat, confirm the verified Builder profile, support contact and policy disclosures, then submit through the available account UI. No GPT ID or store URL exists yet.
