# Phone-ready commercial scope

Prepared 6 October 2026. `/start/` generates a nonbinding pilot brief using non-sensitive selectors, with a run ID, PLANNING mode, input/rate references, limitations and local audit. Prices are proposed assumptions. No lead submission, payment, contract, private customer processing, background job or model call is implemented.

The approved public receiving channel lives in `js/contact-config.js`. Until the owner supplies one, it stays null and the interface offers downloads/manual sharing. A configured email opens a customer-initiated draft; it does not send. Never add credentials or private records to this module.

The manifest and app icons support a home-screen web experience. On iPhone Safari use Share → Add to Home Screen. Network access is required; no offline guarantee or native iOS/Wallet pass is claimed. The current card/about pages were recovered from newer hosted versions and preserved before commercial additions.

Public scoping and the three fictional product workflows execute deterministic rules on demand. Private CEO financial scenarios are hosted separately behind the existing owner-private gateway, with hypothetical inputs and capacity/cost caveats. The financial model, internal business plan, saved owner records and source archives are excluded from this public build.

Checks: `npm run build`, `npm test`, `npm run check:release`, `npm audit --audit-level=high`, `node scripts/pilot-browser-check.mjs`, `npm run test:browser`. Browser checks use installed Chrome or CHROME_PATH. Source branch remains excluded from Vercel auto-deployment while Hobby eligibility blocks this business release.
